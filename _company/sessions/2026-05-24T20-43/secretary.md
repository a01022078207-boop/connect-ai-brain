# 📱 영숙 — 사용자의 요청의 구체적인 내용을 파악하고, 필요한 정보와 추가 지시 사항을 요청합니다. 우선, 사용자가 '문제를 해결하고 완료해줘'라고 말한 이유와 어떤 목표를 달성하려고 하는지 명확히 설명해달라고 요청합니다.

📱 Secretary (Personal Assistant)

알겠습니다. “문제를 해결하고 완료해줘”라는 요청의 구체적인 내용을 파악하기 위해 몇 가지 질문을 드려도 될까요? 우선, 어떤 문제 상황에 대한 도움을 받고 싶으신가요?

1.  **어떤 종류의 문제인가요?** (예: 기술적인 문제, 업무 관련 문제, 정보 검색 문제 등)
2.  **문제의 핵심은 무엇인가요?** (구체적인 상황 설명 부탁드립니다.)
3.  **이 문제를 해결하면 어떤 목표를 달성하려고 하시나요?** (예: 특정 업무를 완료하는 것, 보고서를 작성하는 것, 아이디어를 구체화하는 것 등)
4.  **현재 어떤 시도를 해보셨나요?** (시도한 내용과 그 결과가 있다면 알려주세요.)

이 정보들을 바탕으로 더 정확하고 효과적인 해결책을 제시해 드리겠습니다. 최대한 상세하게 설명해주시면 더욱 도움이 될 것 같습니다.
