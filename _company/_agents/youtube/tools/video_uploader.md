# 📺 유튜브 OAuth 2.0 자동 업로드 설정 매뉴얼

이 도구는 단순 조회용 API Key가 아닌, **보안 쓰기 권한이 포함된 OAuth 2.0 사용자 동의**를 통해 동영상을 사장님 채널에 백그라운드로 안전하게 자동 업로드합니다.

최초 1회만 아래 단계에 따라 Google Cloud Console에서 클라이언트 키를 발급받아 입력하시면, 이후에는 **갱신 토큰(Refresh Token)을 통해 무인으로 영구 가동**할 수 있습니다.

---

## 🛠️ 1단계: Google Cloud Console 설정

1. **프로젝트 생성**:
   - [Google Cloud Console](https://console.cloud.google.com/)에 구글 계정으로 로그인합니다.
   - 우측 상단 프로젝트 선택창에서 **[새 프로젝트]**를 클릭해 프로젝트를 생성합니다 (예: `Breaking Life`).

2. **YouTube Data API v3 활성화**:
   - 콘솔 상단 검색창에 **"YouTube Data API v3"**를 입력하고 클릭합니다.
   - **[사용 설정]** 버튼을 누릅니다.

3. **OAuth 동의 화면 설정**:
   - 왼쪽 메뉴에서 `API 및 서비스` ➔ `OAuth 동의 화면`을 선택합니다.
   - User Type은 **[외부]**로 선택하고 **[만들기]**를 누릅니다.
   - **앱 등록 정보**:
     - **앱 이름**: `브레이킹라이프 자동 업로더`
     - **사용자 지원 이메일**: 사장님 구글 이메일
     - **개발자 연락처 정보**: 사장님 구글 이메일
     - 입력 후 `저장하고 계속하기`를 누릅니다 (범위 설정 단계는 무시하고 저장).
   - **테스트 사용자**:
     - **[ADD USERS]** 버튼을 클릭하여 **동영상을 실제로 업로드할 유튜브 채널의 구글 이메일 주소**를 정확히 입력하고 저장합니다.

4. **OAuth 2.0 사용자 인증 정보(클라이언트 ID) 생성**:
   - 왼쪽 메뉴에서 `사용자 인증 정보`를 선택합니다.
   - 상단 **[+ 사용자 인증 정보 만들기]** ➔ **[OAuth 클라이언트 ID]**를 선택합니다.
   - **애플리케이션 유형**: `데스크톱 앱`을 선택합니다.
   - **이름**: `Antigravity IDE Uploader`
   - **승인된 리디렉션 URI** (만약 활성화되면 입력): `http://127.0.0.1:5814/yt-oauth-callback`
   - **[만들기]** 버튼을 누릅니다.
   - 발급된 **클라이언트 ID**와 **클라이언트 보안 비밀번호** 창이 나타나면 두 값을 복사합니다.

---

## 🔑 2단계: IDE 대시보드에 키 등록

1. **설정값 주입**:
   - Antigravity IDE의 왼쪽 에이전트 패널에서 **YouTube** 설정(⚙️ 아이콘)을 누릅니다.
   - 새로 추가된 **`OAuth Client ID`**와 **`OAuth Client Secret`** 입력란에 복사한 구글 값을 각각 정확히 붙여넣고 저장합니다.
   - (직접 텍스트 파일로 편집하시려면 `_company/_agents/youtube/tools/youtube_account.json`의 `"YOUTUBE_OAUTH_CLIENT_ID"` 및 `"YOUTUBE_OAUTH_CLIENT_SECRET"` 필드에 입력하시면 됩니다.)

---

## 🚀 3단계: 최초 1회 브라우저 인증 수행

1. 업로드할 테스트용 동영상 파일(예: `00_Raw/videos/test.mp4`)을 준비합니다.
2. `video_uploader.json` 설정 파일에 동영상 파일 이름과 업로드할 제목, 설명 등을 작성합니다.
3. 터미널 또는 IDE 도구 실행 버튼을 눌러 `video_uploader.py`를 실행합니다:
   ```bash
   python _company/_agents/youtube/tools/video_uploader.py
   ```
4. **인증 팝업 작동**:
   - 실행과 즉시 브라우저 창이 열리며 구글 로그인 창이 뜹니다.
   - 테스트 사용자로 지정한 유튜브 구글 계정을 선택해 로그인을 진행합니다.
   - **"Google에서 이 앱을 검증하지 않았습니다"** 경고 화면이 나오면 당황하지 마시고 **[고급]** ➔ **[임시 프로젝트(이동)]** 또는 **[unsafe]** 관련 하단 링크를 클릭합니다.
   - 접근 권한 동의 체크박스(유튜브 채널 관리 권한)에 **체크**를 해준 뒤 `계속`을 누릅니다.
5. **완료**:
   - 브라우저에 "The authentication flow has completed..." 문구가 보이면 인증이 성공한 것입니다.
   - 로컬 폴더에 `youtube_token.json` 파일이 자동 생성되며, 영상이 즉시 업로드 진행률과 함께 올라가기 시작합니다!

이후에는 매번 브라우저 창을 켤 필요 없이, 백그라운드 스크립트가 갱신 토큰을 이용해 24시간 언제든지 무인 자동 업로드를 수행할 수 있습니다.
